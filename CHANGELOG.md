## [1.2.1] — 2026-11-16

### Fixed

- The format was never executed: `Invoke-NativeFormat` declared the cluster size as
  `[string]`, so the default `0` became the string `'0'` — truthy — and `/A:0` was
  appended to the command line. `format.com` rejects that parameter (« Paramètre non
  valide », exit code 4) before writing anything, leaving the card untouched.
- The failure was reported as a success: the verdict only looked at the volume file
  system, so a card that was already FAT32 kept its data while the script announced
  « Format completed ». Success now also requires `format.com` to exit with 0.
- `-DryRun` could not catch the bug because it built its own command line, where `0`
  stayed an `[int]` and the `/A:` switch was omitted. Preview and execution now share
  `Get-FormatArguments`, so the simulation prints exactly the command that will run.
- `format.com` output was decoded with the console code page instead of the ANSI one,
  which turned « Paramètre » into « ParamÞtre » in the log and the failure dialog.
- The log now records the volume serial number before and after the format, so a
  support log tells whether the volume was really rewritten.

### Changed

- The build workflow uses `actions/checkout@v7`, `actions/upload-artifact@v7` and
  `softprops/action-gh-release@v3`, all running on the Node.js 24 runtime, which
  silences the Node.js 20 deprecation warning on every run.
- `.editorconfig` saves `*.ps1` and `*.psd1` files as UTF-8 with BOM, so the
  `PSUseBOMForUnicodeEncodedFile` lint failure cannot come back.

## [1.2.0] — 2026-11-13

### Added

- `Build-Package.ps1` builds a portable archive
  (`dist/FormatFAT32-<version>-portable.zip`) with the scripts, the seven language
  files, the launcher, the icon and the documentation — for colleagues who prefer a
  folder to unzip over an installer. The version is read from the installer script.
- `CHANGELOG.md`.

### Fixed

- `Build-Package.ps1` is saved as UTF-8 with BOM: PSScriptAnalyzer's
  `PSUseBOMForUnicodeEncodedFile` rule was failing the lint job on a script with
  French comments and no BOM.

### Changed

- READMEs document the portable archive and the `Build-Package.ps1` entry.

## [1.1.0] — 2026-11-12

### Added

- User interface in seven European languages (English, French, German, Spanish,
  Italian, Portuguese, Dutch), strings in `lang/*.psd1`, English fallback,
  `-Language` parameter and `language.txt` written by the installers.
- Tool-drawn dialogs so the buttons follow the selected language (Windows
  `MessageBox` buttons always follow the OS language).
- Inno Setup installer (`installer/FormatFAT32.iss`): a single `Setup.exe`,
  localized, with per-user installation (`/CURRENTUSER`) and silent deployment.
- `Launch-FormatFAT32.vbs`: the shell verb now runs `wscript.exe` → PowerShell
  hidden, so no console window is ever created.
- Windows build gate: creating FAT32 above 32 GB requires build 26100.8313
  (24H2) or 26200.8313 (25H2) or later; the tool checks it before formatting and
  explains it, with `-SkipVersionCheck` to bypass.
- Application icon (multi-resolution PNG ICO) and README logo, generated by
  `tools/New-Icon.ps1`; real dialog screenshots in `docs/`.
- CI: lint (PSScriptAnalyzer + language-key parity) and installer build; the
  installer is attached to a GitHub release when a `v*` tag is pushed.

### Fixed

- Per-user registration wrote the shell verb to `HKCU\Drive\shell` instead of
  `HKCU\Software\Classes\Drive\shell`; machine-wide and per-user entries are now
  written explicitly to the right hives.
- Upgrading from the legacy PowerShell installer removes its context-menu entry,
  uninstall entry, shortcut and uninstaller.
- The launcher strips the trailing backslash of the drive root (`D:\`), which
  Windows argument parsing would otherwise turn into an escaped quote.

## [1.0.0] — 2026-11-12

### Added

- Context-menu action *Format as FAT32* for drives, quick `format.com /FS:FAT32`
  on removable volumes only, confirmation dialog, UAC elevation, post-format
  verification and logging.
- PowerShell installer and uninstaller (`HKLM` or `HKCU`).
- Bilingual documentation (English, French) and MIT licence.
